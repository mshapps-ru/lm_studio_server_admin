Пранализируй проект и расскажи о нём подробно.

Давай сделаем план разработки проекта админки для LM Studio Server службы Windows который умеет:
1) Приложение консольное
2) Код пишем на c#
3) Приложение должно работать как из консоли так и работать в качестве службы Windows. Для старта в качестве службы добавляем параметр командной строки -service
4) Приложение слушает порт 7778 и при входе на порт 7778 по http появляется страница авторизации с именем пользователя и паролем
5) После авторизации появляется страница с двумя вкладками "Home" и "Settings". Также должна быть кнопка "Exit" для выхода из админки LM Studio Server
6) На вкладке "Home" можно проверить статус LM Studio Server, также можно кнопками остановить и запустить LM Studio Server командами:
- lms server start             Starts the local server
- lms server stop              Stops the local server
- lms server status            Displays the status of the local server
7) На вкладке "Settings" должны быть настройки:
- имя пользователя и пароль для входа в админку
- порт который слушает приложение, по умолчанию порт 7778
Все настройки приложения храним в json файле который лежит в каталоге рядом с exe файлом
8) Статус LM Studio Server проверяем по расписанию раз в минуту и отображаем на странице "Home"
